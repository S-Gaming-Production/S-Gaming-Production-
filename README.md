## 🎮 Our Project

### Assassin's Creed Independence

**Assassin's Creed Independence** is a fan-made, story-driven action-adventure game set in **1939 Bengal, British India**.

The project follows **Serma Hembram**, a skilled Assassin who becomes involved in a dangerous conspiracy surrounding Medinipur.

### Features

- 🗡️ Stealth gameplay
- 🏃 Parkour and free-running
- 🌍 Open-world exploration
- 🎭 Story-driven missions
- 🔎 Investigation and discovery
- ⚔️ Assassin-style combat
- 📱 Mobile-focused development
- 🎮 3D gameplay
- 🏛️ Historically inspired Bengal setting
